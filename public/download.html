Installing

Install, then sign in with your MetaCode account.

Windows

  1. Open the downloaded .exe.
  2. Choose where to install it, then Install. No administrator rights are needed.
  3. Open MetaCode Sheets from the Start menu or the desktop.

If Windows SmartScreen says it doesn't recognise the app, first check the file's SHA-256 against this page, then choose More info → Run anyway. IT departments can deploy the .msi instead.

macOS

  1. Open the downloaded .dmg.
  2. Drag MetaCode Sheets into Applications.
  3. Open it from Applications or Launchpad.

If macOS says it can't check the app for malicious software, check the file's SHA-256 against this page, then go to System Settings → Privacy & Security and choose Open Anyway.

Linux

  1. AppImage: make it executable and run it — chmod +x MetaCode-Sheets-*.AppImage, then ./MetaCode-Sheets-*.AppImage.
  2. Debian / Ubuntu: sudo apt install ./MetaCode-Sheets-*.deb, then open it from your applications.

Your session is kept in the system keychain (libsecret / GNOME Keyring or KWallet). Without one you sign in each time you open the app.

Sign in with the same email and password you use on this website. MetaCode Sheets checks your plan with MetaCode, then keeps working offline for up to a few days between checks. AI features need a connection.
